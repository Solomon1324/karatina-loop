# Karatina Loop

A student community for Karatina University in Kenya, designed around 50+ groups and a 10,000+ member goal.

This project includes group communities with chat and photo sharing, student business listings, useful campus information, moderation tools, and a site admin dashboard.

## Getting started

1. Install Node.js and pnpm.
2. Copy `.env.example` to `.env`.
3. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` in `.env`.
4. Run `pnpm install`, then `pnpm dev`.

See `SUPABASE_SETUP.md` and `DEPLOYMENT_CHECKLIST.md` for setup and hosting. Do not commit `.env` or any Supabase secret/service-role key.
